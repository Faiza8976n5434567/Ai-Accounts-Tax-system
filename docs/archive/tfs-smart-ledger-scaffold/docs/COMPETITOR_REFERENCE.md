# Competitor & Reference Products (researched Sep 2026)

| Product | Positioning | What to learn / borrow | Where we differentiate |
|---|---|---|---|
| Zoho Books (UAE edition) | SME all-rounder; free tier; FTA-accredited and a Digital Tax Integrator (direct VAT filing to EmaraTax); Zia AI assistant | Breadth, client portal, direct filing integration, low entry price | No human tax agency behind it; generic CT support |
| Wafeq | UAE/GCC-built cloud accounting; VAT, CT, e-invoicing, Arabic/English, auditor portal, WPS | UAE-first UX, bilingual invoices, auditor access | We add managed review by an FTA tax agency + firm master console |
| QuickBooks / Xero | Global SME ledgers; AI assistants (Intuit Assist, Xero JAX) | Ecosystem & app marketplace, bank-feed UX | Not UAE-native for CT/e-invoicing detail |
| Tally Prime | Traditional desktop, strong in trading SMEs | Speed of data entry, inventory | Cloud, AI, multi-client firm view |
| RQM Books | UAE cloud ERP for trading/manufacturing; FTA-registered | Inventory/costing depth | Services/SME focus + tax advisory layer |
| Mazeed ONE, Kitaab, TaxOS, Qaspro | UAE SME/freelancer tools mixing software with tax experts | "Software + expert" bundles exist — validates our model | Depth of CT/TP/e-invoicing expertise; multi-ASP |
| Digits (US) | AI-native "autonomous general ledger"; Agentic Close; firm dashboard; outcome-based pricing | Continuous close, manage-by-exception, confidence-based automation, firm portfolio view | Build the same philosophy for UAE rules |
| Qoyod / Daftra (KSA) | GCC SME accounting with ZATCA e-invoicing baked in | Treat e-invoicing as core, not add-on | UAE PINT AE focus |

Key takeaways:
1. Basic VAT-compliant bookkeeping is commoditised (free to ~AED 300/month). Don't
   compete on software price alone.
2. AI-native competitors win on "manage by exception" — continuous categorisation,
   reconciliation and close, not a chatbot bolted on.
3. The unserved gap in the UAE: a platform where an FTA-registered agency is accountable
   for the output (VAT, CT, e-invoicing, audit-ready FS) and runs many clients from one
   console.
